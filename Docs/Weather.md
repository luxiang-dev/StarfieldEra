# 天气与预知未来

按 **Y**，点击顶部「天气」，或进入旅人手册的「天气」页。

## 配置与真实天气

`WeatherType` 包含 Sunny（晴天）、Cloudy（多云）、LightRain（小雨）、HeavyRain（大雨）、Thunderstorm（雷暴）。每类天气对应一个 `WeatherDataSO`：名称、全彩图标、草图图标、温度范围、风力描述、当日增益、老农谚语及实际作物/采集效果。

配置资源在 `Assets/StarfieldEra/Resources/Weather/`；Unity Inspector 可编辑各天气属性。`StarfieldEra/Set up weather data and icons` 可生成缺失的配置与图标，保留已有天气参数。

真实队列保存在 `FarmState.weather.trueWeatherQueue`，共7项：今日以及随后6天。今日、明日直接使用真实值。结束一天时移除今日、补入末日，已知未来天气不变。队列、种子、日期、技能等级与升级材料均保存；旧存档补齐天气系统，今日、明日按旧天气取最接近的新天气类型。

## 经验判断

| 等级 | 可预判 | 升至该级消耗 |
| --- | --- | --- |
| 0 | 无 | — |
| 1 | 第3天（后天） | 生存经验20、星石1 |
| 2 | 第3～4天 | 生存经验50、星石3 |
| 3 | 第3～5天 | 生存经验90、星石5 |

置信度公式：`Clamp(0.55 + 等级×0.10 − (第N天−3)×0.08, 0.50, 0.90)`，显示为最近的5%整数。两项候选天气互不重复、合计100%；主预测按该基础准确率选择，可能判断错误。干扰项优先选择相邻天气，例如大雨更接近雷暴、小雨或多云。

同一天、同一等级的判断稳定，不会因重开页面或读档重抽。提升技能后会更新判断，未来日期缩短时也会重新评估。第3天真实天气决定底部的经验谚语，其表述属于经验提示。

生存经验来源：收获作物+2、手动采集+1、成功钓鱼+2、解读石碑+2、击败守卫+5、结束一天+1。星石来源：开采晶石+1、远方宝箱+1、击败守卫+1。星石与原有晶石是独立材料。

## 当日增益

- 晴天：湿润作物生长速度+10%，小数进度随存档保存。
- 多云：手动采集木材额外+1。
- 小雨：农田与幼树自动补水。
- 大雨：自动补水，湿润作物生长速度+10%。
- 雷暴：自动补水，手动采石额外+1；场景呈现大雨与间歇闪光。

UI 使用 TextMeshPro、UGUI Image 和填充进度条。左侧显示今日、当日增益、明日；右侧显示升级消耗与节点、三列草图概率预测和老农便签。

验证：37项编辑器测试全部通过，覆盖队列推进与存档、预测等级/概率/稳定性、统计错误率、升级原子扣料、雨水、生长增益与旧存档迁移。Unity Play 验证了等级0与等级3界面、6条实际概率填充条、升级和读档。
