# 地块类型与通行规则

每个六边形保存独立的 `TerrainKind`，通行、速度和建造规则读取地形数据。材质名称和颜色不再决定能否通行。当前大陆仍为 1,681 格，地图布局固定。

| 地形 | 移动速度 | 建筑与围栏 | 位置与表现 |
| --- | --- | --- | --- |
| 草地 | 100% | 可建 | 中央与金穗平原，草绿色 |
| 森林 | 80% | 可建，仍须避开树木 | 青苔森林、驿站及散布林地，深绿 |
| 沼泽 | 45% | 不可建 | 幽光湿地，灰绿色与芦苇 |
| 沙地 | 80% | 可建 | 湖岸、河岸和散布沙地，黄褐色 |
| 岩地 | 70% | 可建 | 遗迹和白岩山地，灰色 |
| 雪地 | 65% | 可建 | 白岩山地东北，浅白色 |
| 道路 | 120% | 可建 | 村庄广场与主要道路，浅土色 |
| 水面 | 不可通行 | 不可建 | 镜湖、农场池塘、东部河道、西侧小湖、湿地水洼，蓝色与波纹 |

建筑还须满足原有完整占地、障碍、人物、农田预留范围、费用等条件；所有占地必须是可建地形。牧场围栏两侧须为稳定陆地，不能放在水面或沼泽边缘。

玩家、野猪、随行伙伴使用相同水面通行规则。玩家与野猪按脚下地形改变速度；随行伙伴仍采用跟随插值。玩家移动按短步检查并计入角色半径，碰撞滑动后也检查岸线，避免在低帧率或斜向移动时跨过水域。旧矩形水域障碍不再作为湖岸判定，新老水域统一按六边形边界阻挡。

新水域避开资源点、已有建筑和围栏的相邻格、已存档动物所在格。加载旧档与快速旅行会寻找安全陆地，保持天数和资源。底部交互标题显示当前脚下地形和移动比例，旅途地图说明沼泽、水面与道路特性。

目前没有游泳、船只、可建桥梁、地形改造、泥地足迹、地形战斗加成或地块种植收益。农田仍使用原有种植规则。

本次仅验证 Unity 编译、地图实际生成八类地形、一次岸线阻挡计算与原存档有效性；未运行完整测试套件或重新构建平台版本。
