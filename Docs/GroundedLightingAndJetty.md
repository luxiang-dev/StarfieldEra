# 接地光照、标签与镜湖码头

PC（Linux/Windows）URP 配置使用 110 米阴影距离、四级联与柔和方向光。SSAO 使用现有 Renderer Feature，强度 1.05、半径 0.38、半分辨率和双边模糊，不重复添加。通过菜单 `StarfieldEra/Configure grounded storybook lighting` 可重建这些配置。

手绘模型、连续地表和草地沿用原绘制颜色，接入 URP 原生光照以支持级联阴影、聚簇点光源与屏幕空间环境遮蔽。模型增加匹配纹理透明裁切的 ShadowCaster、DepthOnly 和 DepthNormalsOnly 通道；地面使用不透明深度与法线通道。备用树石广告牌继续朝向相机，并可投射裁切轮廓阴影。原先的手工平面阴影贴片不再生成。材质转绘时保留自发光遮罩，未启用自发光的旧材质不会整块发亮。

沿用一个 Global Volume：Neutral 色调映射、对比度 +10、略暖滤色、Bloom 阈值 0.9 / 强度 0.6、暗角 0.22。主方向光斜向照射，降低阴影偏移，便于俯视时看清树木与房屋的落地投影。

农舍与码头各增加一个暖橙色灯笼及范围 4.3 米的点光源；古门为 4.5 米紫色点光源，紫色晶石和石碑符文使用 HDR 自发光。点光源不投影，避免额外阴影贴图成本。运行时生成的材质由所属组件回收。

人物、资源点与探索地标标签改为被动 World Space Canvas，含共享圆角 Image、深色半透明底板、共享 TMP 描边材质；朝向主相机，保持原有近距离显示规则。它们不接收射线，不增加 EventSystem 或 GraphicRaycaster。固定字号不启用 AutoSize，中文字体资产保持共享。

镜湖码头使用八条错落木板、钉帽、纵梁、浸水支撑桩和金属箍。木纹 Shader 以世界水位控制木材变暗与苔色，四根木桩附近显示循环扩散水纹。这是装饰性的水面响应，不进行流体模拟；原有钓点、地形通行和存档逻辑保持不变。
