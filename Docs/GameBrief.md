# 星野纪元：首个原型简要

## 定位

3D 低多边形、俯视与斜俯视相机、单人、Linux / Windows。借鉴农场经营、文明发展和伙伴收集的玩法类别，世界观、角色、生物、美术与名称使用原创设计。

## 核心循环

经营农场获取食物与材料 → 探索邻近区域并结识生物伙伴 → 将资源与伙伴能力投入城镇建设和科技研究 → 回合制战斗解锁新的区域 → 回到农场继续发展。

日常操作以探索和经营为主；睡觉结算一天，同时推进作物、城镇生产与科技。战斗进入独立回合，避免让三套时间系统同时推进。

## 第一阶段：小型可玩闭环（待实现）

1. 一块可探索的小地图，包含农场、聚落和野外；先使用方格，六边形文明地图留待后续评估。
2. 玩家移动与交互，种植、浇水、隔天收获一种作物。
3. 一种原创野生伙伴，通过一次简化遭遇招募；伙伴可提升一种生产能力。
4. 一座可建造的设施与一项可研究的科技；资源消耗和完成时间可见。
5. 一场一对一回合制战斗，包含攻击、技能、退出与胜负结算。
6. 本地存档，保留日期、资源、农田、城镇与伙伴数据。

## 范围边界

首个原型不加入多人、商业化、完整外交、复杂季节、海量生物、繁殖或大型科技树。先验证各系统之间的资源流动，再扩充内容。

## 推荐实现顺序

地图与移动 → 一天经营循环 → 资源与城镇 → 伙伴与战斗 → 存档 → 低多边形美术替换。

## 完成标准

玩家能够种田收获、招募伙伴、建设一座设施、研究一项科技、赢得一场战斗，并在重新打开游戏后继续进度。

## 当前状态

已完成农场循环，并扩展为四个探索区域、十二处每日采集点、三种伙伴、三段村长委托、两种建设、两项科技和遗迹回合制战斗。详见 ContentGuide.md。下一阶段扩充作物、村民、敌人、伙伴成长和城镇领土。
