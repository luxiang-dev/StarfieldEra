# 土地改造与生态

按 **H** 打开旅人手册的「土地工具」页。选择工具后回地图，左键选择六步内地块，右键或 Esc 取消。绿色允许施工，红色显示原因。建筑、原农场、围栏、资源任务点和牧场受到保护，挖河、填埋和植树也会避开角色及动物。

| 工具 | 费用 | 效果 |
| --- | --- | --- |
| 开垦 | 体力2 | 草地、沙地变成带土垄的新农田 |
| 植树 | 体力2、木材2、浆果1 | 树苗经三个滋养夜晚长成，成熟后周边保湿 |
| 挖河 | 体力3 | 开挖河床并得到土方3；连通水源且地势允许时进水 |
| 填埋 | 体力3、土方2、石料2 | 水面或干河床成为沙地；截断水源会令下游人工河道干涸 |
| 复绿 | 体力2、纤维2 | 裸沙土或空耕地覆草，恢复草地 |
| 查看 | 免费 | 显示地形、湿润程度、连续干旱、河道状态和树苗成长 |

新开农田按 **E** 播种或收获，按 **R** 浇水，使用背包选择的种子；作物天数、收益、消耗与原农场一致。新农田不会占用原有24块地的索引。树苗旁按 **R** 也可以浇水。

天然水源与连通的河道为邻接地块保湿；已有森林、成熟栽植树木在约两格内固土。灌溉技术研究后，邻接水面的新农田自动浇水。仅潮湿不会代替作物浇水。

改造过的裸露土地或空农田，夏季连续干旱4天、其他季节8天会沙化；雨水和植被会减少干旱积累。有作物的农田受到保护，不会被沙化直接清除。原始地图的景物不会被全图生态结算破坏。新树苗需要雨水、水源、成熟林木或手动浇水才能成长，缺水会暂缓生长。

地形枚举仍负责通行与建造，视觉地表、河床、水面、草丛和小地图同步更新。河道连通使用六邻格搜索和简化地势约束，不是流体模拟。水面不可行走，填埋后的沙地可通行。改造记录、土方、树苗、土壤干旱和新农田作物保存在原存档中；旧存档自动补上空记录。当前最多512格改造记录。

## 引水修正

水源连通与渲染共用 `CanalHydrology` 的湖面高度；连通的河道自动下挖到湖面以下0.6米，常规河道最多处理1.8米岸坡高差。修复了之前仅降低0.22米、且以湖底原始地形高度误判水位，导致靠岸河道仍高于水面的情况。过高的岸坡会在施工前提示绕行低处；未接通水源时明确显示干河道原因。旧存档已经开挖的河道会在加载时重新计算，自动接水，不再次收费。填埋则立即按修改后的地块状态重新计算水源，避免将刚填平的地块误认作湖水。

本次针对实际存档验证：西南湖岸两格旧河道恢复进水，河床低于同一湖面0.6米；其他三格未接到水源的河道保持干涸。修复前后天数、金币、体力、土方保持一致。
