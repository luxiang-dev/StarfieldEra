# 工具、装备与图纸

L 打开制作，分为装备制作、装备图纸、料理与补给。I 打开背包，装备分页显示持有状态、用途和图纸状态。土地页面会说明缺少的工具，并可直接跳到对应图纸。

新游戏及旧存档保留六件基础农具及其图纸：锄头、水壶、斧头、镐、建造锤、镰刀。这样基础耕作、采集与建筑不会因缺少材料陷入循环锁定。其余装备需要先学习图纸，再支付制作材料；学习不代表已经持有装备。持有即自动用于操作，无额外装备切换与耐久消耗。

| 操作 | 必须持有 |
| --- | --- |
| 开垦、播种、覆草复绿 | 农用锄头 |
| 农田或幼树浇水 | 浇水壶 |
| 收获、纤维采集 | 收割镰刀 |
| 木材采集 | 伐木斧 |
| 石料与晶石开采 | 采矿镐 |
| 建筑、围栏建设与拆除 | 建造锤 |
| 挖河、引水、填埋 | 工程铁铲 |
| 种植树苗 | 工程铁铲与育林手套 |
| 湖岸钓鱼 | 木制鱼竿或精制鱼竿 |

图纸在小屋、商人或村长旁学习，金币费用分别为铁铲12、木制鱼竿6、育林手套8、精制鱼竿18、湿地长靴20、星辉护符30。基础图纸已掌握。精制鱼竿还需木制鱼竿和工坊；湿地长靴需工坊；星辉护符需书院。所有装备在小屋、营地或工坊旁制作。补给维持原有规则。

装备和图纸分别写入 ExpeditionState.equipment。旧存档已有鱼竿、长靴和护符会同步为持有并保留图纸；已有精制鱼竿同时兼容木制鱼竿资格。禁止操作的检查发生在扣除体力、材料、鱼饵和每日采集次数之前。已有河道、农田、树木和建筑不会因缺少新工具消失。
