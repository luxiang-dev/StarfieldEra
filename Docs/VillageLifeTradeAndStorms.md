# 村民生活、村庄订单、商队、探索路线与暴雨积水

## 入口

- 点击城镇议事牌并交互，打开独立的村庄订单窗口；窗口内可进入商队、路线建设和原有城镇研究。
- 点击新增村民，或在建筑管理窗口点击村民分工按钮，查看村民生活、派工与口粮。
- 地图新增雾松谷、赤晶矿谷入口标记；点击标记查看路线，不会绕过施工解锁。
- **J** 土地面板新增“修排水沟”；**H** 仍为建造。

## 村民职业与生活

初始3位具名村民，对应原来的工人数；旧存档已有派工和库存保留。专长分为伐木、采矿、加工。旧的派驻/召回按钮也会操作同一套村民记录，不能产生额外工人。移动建筑沿用原岗位ID，拆除后释放原派工。

每位村民每天消耗口粮1。初次接入提供口粮9，之后由玩家补充：胡萝卜3换口粮3、鲜鱼2换口粮4、浆果3换口粮2、料理1换口粮6；不会自动扣取背包食物。住房沿用原有基础3床位、每座居民房屋增加2床位、最多9床位的规则；有空床位时，可以消耗金币20和口粮6招募新村民。

吃饱并在匹配专长的岗位工作，每个工作日增加5%效率，最多30%；饥饿效率乘70%，缺床位再乘80%，数量按整数结算。固定工坊原有自动木材收入保留，派驻加工的产量受村民效率影响。村民会在岗位、村庄餐桌区域与住宅附近活动，复用现有人形走路/待机动画，避开水面与实体障碍。

## 议事牌订单与商队

每4天一期，每期3份订单，在本期第4天结束前交付；过期失效，不扣材料。接受和交付都需走近议事牌，物资不足不会部分扣除，完成后不能重复领奖。订单提供金币、声望与经验；“修桥木板”“矿道哨塔石砖”订单还分别抵扣对应探索路线的木板、石砖成本。

商队在每期前2天停留于村口（2，10），需走近后交易。货品包括星辉南瓜种子、工程铁铲/育林手套/湿地长靴图纸、村庄旗帜和口粮。库存按期保存，下期重置；已掌握的图纸不能重复购买。

星辉南瓜使用真实种子、可以在原农田或新开农田播种，5天成熟，收获金币60和口粮3。普通种子商店不出售该种子。旗帜购入背包后可在人物身前的空陆地放置，附近可以收回并重新布置。

## 暴雨、积水与排水沟

大雨和雷暴按低洼程度、地势和既有积水计算新增水量，晴天/多云逐渐退水。水深、位置和结算日期保存；重复加载或刷新不会重复降雨。积水使地面形成临时湿洼，水面独立渲染；退水后恢复原有永久地形，不覆盖玩家保存的山丘/土方改造。

浅水移动速度乘65%，HUD同步显示积水与实际速度；32厘米及以上禁止通行，8厘米及以上禁止建造；超过15厘米的农田暂停成长和耕作，排水后恢复，不直接删除作物。天然水体、道路与受保护的建筑基础不会被当作暴雨洼地处理。

铁铲可在空陆地修排水沟，花费体力3、石料1；再次使用同一工具可移除。沟槽接通天然水源或更低的出水口后形成有效排水网络，不能逆势爬坡；两格范围内有效排水能力为38厘米，孤立沟槽仅渗排6.5厘米。工具会显示是否连通；沟槽占地受到保护，需先拆除才能填土或改建。
