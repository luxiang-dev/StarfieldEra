# 兔子与资源点经营

Unity Play 中按 Tab 打开旅人手册，进入「城镇 → 牧场与经营」。「任务 → 寻兔委托」也可打开兔子页面。点击野兔或在身旁按 E 可查看；点击林场、采石场可直接管理生产。

## 兔子

- 五只野兔在农场东南、约 [8,-8] 至 [18,-14] 活动，未经引诱时靠近会逃跑。位置会避开水面与障碍，手册显示实际坐标。
- 金萝卜每次收获仍按原规则售出，额外保留2份胡萝卜供动物使用；小屋或商人旁也可用6金币买3份。
- 六步内选择兔子，投放1份胡萝卜后返回世界。诱饵持续25秒；手册打开、战斗期间不消耗诱饵时间。
- 等兔子靠近两步内，按 E 或点击它，再选择捕捉。一次最多携带1只。
- 回小屋门前，在牧场页选择「安置携带的兔子」。兔舍在小屋南侧，最多饲养3只。
- 走近兔舍四步内，选择兔子，每天可喂1份胡萝卜。可随时走近兔子选择放回野外，空出兔舍位置。喂过的兔子次日照料天数+1、照料收益4金币；未喂不产出。
- 村长身边可接一次寻兔委托，再交还一只携带的兔子，或已照料一天的兔舍兔子，获得30金币与2份胡萝卜。交还后兔子离开牧场。

## 经营

- 两个固定废弃资源点位于东侧林区约 [19,-10] 和遗迹东北约 [20,18]，实际位置见经营页。
- 六步内花费木材4、石料4、金币10修复为一级。
- 村庄初始3名可派驻村民，建房可增加至9人，每处最多2人；可通过手册随时派驻与召回。没有村民就不生产。
- 每次回小屋休息，每名村民按一级2份、二级3份、三级4份原料生产。林场产木材，采石场产石料。
- 二级升级费用：木材8、石料6、金币20。二级解锁加工开关：每名村民每天用2份库存原料生产1份木板或石砖。
- 三级升级费用：木材12、石料10、金币35、木板2、石砖2。
- 原料、成品库存初始分别最多30份，建仓库可扩至120份；满仓后相应生产停止。走近六步内领取库存，原料进入背包，成品可用于三级升级。
- 自建林场和采石场直接为一级，同样需要分配村民；旧存档建筑自动升级数据格式，资源、日期与其他进度保留。拆除自动回收库存、释放村民。
- 原有城镇「工坊」仍按原规则直接提供木材，与经营资源点分别结算。

兔子、石柱和生产建筑复用已导入的本地模型。本轮无需额外调用混元生成模型。

营地扩建和夜袭规则见 [营地建设与夜间守卫](CampDefense.md)。
