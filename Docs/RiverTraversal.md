# 河流通行与初始资源

新存档金币、木材、石料各1000。当前本地存档也只修改这三项资源，原文件备份位于 `/tmp/starfield-river-backup/`。

玩家可直接进入河流，在河床上以正常步行的50%速度移动；水中不奔跑，空格可从河床起跳返回岸上。跳跃高度提高到1.6米，Shift奔跑配合空格可以跨过窄河。空中经过水面保持正常移动，不再被岸线检测推回。角色在水中保存后可继续从相同位置的河床载入。

本次提供浅水涉行，没有增加游泳动画或潜水系统。NPC、建筑选址仍采用原来的干地规则，区域解锁与地图边界继续生效。

验证仅进行编译与一次集中检查：初始资源、河床移动、下水后起跳、角色不会被水域恢复逻辑推回，以及NPC水域限制。原游玩进度在检查后恢复，再应用用户要求的资源数量。
