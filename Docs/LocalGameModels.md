# 本地主角、野外首领、石头与宝箱

使用 `/home/lx/模型/主角`、`石头`、`宝箱` 中提供的 GLB。原始文件不修改；游戏用 FBX 与 2048 像素颜色贴图存入 `Assets/StarfieldEra/Environment/LocalModels`。

- 主角换为新的冒险少年，身高约 1.78 米。原模型没有骨骼，新增基础骨骼、待机和原地行走循环；真实位移驱动动画，CharacterController 和六边形地形限制保持有效。
- 现有野蛮人从玩家位置移到白岩区域，作为“白岩首领 · 野蛮人”，身高约 2.6 米。复用原来的白岩守卫战斗编号、奖励、每日挑战记录和解锁条件，避免旧任务及存档失效。保留野蛮人的骨骼与动画，在游戏副本上减面，原模型与角色制作文件保留。
- 地图边界、矿石资源点、山地石料点、手绘岩石装饰与采石场外观使用新苔石模型；采集目标、材料产出及原有碰撞保留。晶石矿的紫色晶体仍用于辨认资源类型。
- 八个补给宝箱换为新木箱，保持位置、可交互范围、存档编号与奖励。将整块模型拆为箱体和带铰链的箱盖，已开启状态由原有存档决定，不会重复发奖。

生成顺序：用 Blender 运行 `Tools/Blender/import_game_models.py`、`rig_hero.py`、`prepare_chest_boss.py`，再在停止运行的 Unity 中执行菜单 `StarfieldEra/Set up local hero, rocks, chests and boss`。最后一步通过 Editor API 创建材质、动画控制器及资源预制体，无需手改序列化资产。

减面预算：主角约 22000 面、石头约 6000 面、宝箱约 12000 面、野蛮人约 22000 面。新主角动画为基础自动绑定，尚未制作专用挥工具和攻击动作。
