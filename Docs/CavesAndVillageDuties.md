# 矿洞探索与村民自动岗位

## 入口与战利品

小屋西北附近增加“旧矿洞入口”，可点击后按E进入独立地下空间；从出口营地帐篷返回。地上与地下目标分层选择，地下禁用地表建造、快速旅行与野营，继续支持移动、奔跑、跳跃及背包。地下无雨雪，使用独立灯光、地面碰撞和相机高度。

- 六处矿脉：四处赤铜矿、两处星铁矿，消耗体力3并需要采矿镐。
- 四名精英守卫（180或220生命）、一名矿主首领（900生命）。沿用现有路障、铁桶、壮汉模型与动画；点击后E近战，击败可获取金币。
- 两个宝箱，矿主密藏需要击败首领。宝箱提供金币、矿物及尚未学习的工具图纸；首领提供星铁、矿主碎片，首次额外给星石3。
- 矿物、宝箱和敌人生命即时保存，重复交互不重复发奖。矿主被清除三天后，再次进入会重置矿洞资源与守卫。
- 特殊矿物在背包材料页查看，普通采石场不会产出。在矿洞入口选择“升级矿镐”，一级消耗赤铜8、星铁3、金币30；二级消耗赤铜16、星铁6、金币30、矿主碎片1。升级增加采矿收益与矿洞近战伤害。

## 村民自动岗位

点击村民，进入现有“村民生活”面板，选择搬运工、维修工、巡逻守卫；与原生产岗位互斥，共用现有村民和住房。原存档村民默认为原岗位，不强制改派。

- 搬运工实际步行到资源点或工坊，领取最多100原料与40成品，携带箱子走到仓库（无仓库则小屋前）再存入共享库存。工坊按原规则从共享库存使用原料，因此搬运可自动补充加工供应。运输中的货物也保存，改岗后先送完已有货物。
- 维修工自动寻找受损城墙、围栏和生产设施；每次消耗木材2、石料1，恢复城墙100生命、围栏全部损伤或设施35损伤，间隔4秒。缺料时显示原因，不免费维修。
- 守卫在营地与已修复生产设施之间巡逻，追击附近地上僵尸并在视线畅通时攻击；也可驱赶夜袭野狼。每位守卫有攻击间隔，不能隔墙命中。
- 饥饿达到两天暂停自动岗位，仍需补充村庄口粮。面板显示岗位实时状态。管理暂停时自动岗位与战斗一并暂停。

岗位逻辑每秒检查一次，沿用现有村民移动和避障，复用已有模型，不调用模型生成服务。当前是单座矿洞和基础岗位系统，未添加程序生成洞层、NPC装备或NPC受伤成长。

## 必要验证

编译通过；一次集中运行检查覆盖搬运领取/入库、货物存档校验、维修材料事务、守卫派岗、矿洞进入、专属矿采集、首领/宝箱防重复奖励、存档往返与出口。另针对地下相机、地板碰撞和贴地做了画面核对并修正；未运行全套测试。检查后原主存档及备份逐字节恢复。
