# 僵尸选中轮廓与资源点增产

僵尸模型带有100倍导入缩放。选中蒙皮网格改为显式 `BakeMesh(mesh, true)`，再应用渲染矩阵，避免黄色轮廓被重复放大。四种僵尸轮廓网格的实际高度核对为约1.82～2.21米。

伐木场与采石场的每日原料、加工产量提高10倍。基础效率、两名工人时，一级80、二级120、三级160原料/日；三级开启加工后为80原料与40成品/日。无人、停工和受损停产规则继续生效；村民生产力仍影响实际产量，管理面板预测使用同一公式。

基础库存300，每座仓库增加300，上限1200；库存存档校验同步扩大，兼容原存档。

代码中的新存档金币、木材、石料均为1000；本次读取当前本地存档确认也是三项1000。仅做编译与一次针对性集中检查，没有运行全套测试。
