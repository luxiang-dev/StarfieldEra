# 石头开采与围栏连接

- 地图中的独立石头模型（矿石资源点、农场边缘石头、装饰岩石与小石块）统一接入开采。走近后按 E 或底部交互按钮，需要持有初始采矿镐；第一人称须面向石头。
- 每次消耗体力 2，获得石料 `3 + 工具等级 × 2 + 当日天气加成`，生存经验 +1。原矿石点也走同一套流程，不会再按日重复领取。
- 采完立即移除碰撞、矿石标签和模型，播放 0.8 秒碎片飞散、缩小消失效果。碎片没有碰撞，不会阻碍移动。
- `MiningState.depleted` 保存采空位置，读取旧存档自动初始化；读档、过夜和改变地面高度不会恢复已采空的石头。建筑本体、山体地形、古代石柱不作为独立石料采集。
- 重新选择围栏起点时，自动吸附半径扩大到 1.15 米；绘制终点时吸附 0.7 米内的其他立柱，并排除当前起点，避免自身遮蔽附近连接点。连续建造、重新选择围栏和牧场门均使用这一逻辑。
- 原围栏模型立柱的烘焙中心存在偏移，实例化时将两根柱子的水平中心分别对齐到存档端点，再隐藏重复立柱；模型与围栏闭合判定共享同一套位置。

验证：68 项 EditMode 测试通过；场景实测 37 个独立石头全部接入，普通石头与矿石点均开采成功，石料 +3、体力 -2、经验 +1，重复采集无奖励；10 个碎片正常生成并清理。重新进入游戏后，两块已采空石头保持隐藏，围栏与门端点完全一致，立柱水平偏差小于 0.000001 米。测试结束恢复原始存档。自动回归测试覆盖采空存档、旧档升级、无效记录、同格续建、近距离闭合、门连接与远距离独立摆放。
