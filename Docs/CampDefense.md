# 营地建设与夜间守卫

入口：Tab → 城镇 → 营地与守卫。G 建造菜单第二页也提供房屋、仓库、陷阱入口，下一页为已有围栏与牧场门。

## 建设

| 建设 | 费用 | 作用 |
| --- | --- | --- |
| 居民房屋 | 木10、石6、金15 | 占4格，可旋转；村民容量+2，最多9人；靠近房屋也能休息 |
| 仓库 | 木8、石8、金12 | 占4格，有可见货箱；所有资源点原料与加工品的库存上限各+30，最多120 |
| 木围栏 | 每段木2 | 阻挡野兽，遭三次啃咬后这段围栏损坏消失 |
| 牧场门 | 每扇木4 | 关门阻挡野兽，开门允许通行 |
| 捕兽陷阱 | 每处木2、石1 | 布置在角色六步内、已修复资源点八步内的空地；触发后击退一只野兽并消耗 |

房屋和仓库复用本地模型与现有建筑美术。点击建筑查看，拆除返还一半基础费用。拆房前须召回超出新容量的村民。拆仓库保留已有库存，超出新容量的部分领取前不再增加。

陷阱可连续放置，间距至少0.9米；最多24个未消耗陷阱。右键、Esc或手机取消按钮退出布置。触发后留下暗色残架，补充陷阱时清理旧残架。

## 夜袭

- 第3、6、9……天结束时，有派驻村民的已修复资源点会遭袭，目标依日期在符合条件的资源点间轮换。
- 营地页提前显示当晚目标。先去目标附近围建、关门、布置陷阱，再回小屋或居民房屋休息。
- 休息会将玩家带到受袭资源点旁，切换夜色，守卫60秒。共三波，每波2只野兽，分别在开始、第18秒、第36秒出现。
- WASD移动；E或画面驱赶按钮攻击三步内最近的野兽，每只需三次驱赶。攻击间隔0.55秒，无体力消耗。
- R或修补按钮：设施六步内花木2石1修补25点耐久，守卫中间隔3秒。
- 陷阱接触野兽后自动触发。野兽会啃咬关闭的围栏，每段承受三次；围栏可在白天点击后花木1修补。
- 设施满耐久100；野兽每次攻击造成5点损伤。玩家守卫体力8，被近身攻击时减少，降至0则守卫失败。
- 击退全部三波或守到天亮即胜利，奖励15金币。设施被毁或玩家守卫体力耗尽则失败：受袭设施库存、成品各损失一半，并停止本次次日生产；其他资源点正常生产。
- 守卫结束自动回到休息地点、推进一天并恢复日间天气。损伤保留，可在经营页、营地页修补。完全损坏的设施需先修补才能生产。
- 守卫中暂停建造、手册、传送与常规遭遇战；退出或切到后台会保存夜袭进度，重新进入继续守卫。

所有新数据随原农场存档保存。旧存档自动补齐新系统，原有兔子、资源点、建筑与进度保留。

验证：28项编辑器测试全部通过；Unity Play 验证了房屋与仓库建造、陷阱触发、围栏三次受击破损、驱赶、修补、胜负结算、夜袭退出后继续，以及拆除房屋容量限制和仓库超额库存保留。测试后恢复原始游戏进度。
